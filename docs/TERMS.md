# Omni — Kullanıcı Anlaşması

Omni'yi kullanarak aşağıdakileri kabul etmiş olursun:

1. Bu araç yalnızca kişisel kullanım içindir.
2. Başka kullanıcıları rahatsız edecek, oyunu bozacak şekilde kullanmayacaksın.
3. Hesabının yasaklanma (ban) riski sana aittir.
4. Araç "olduğu gibi" sunulur, garanti verilmez.
5. Bu repodan türetilen hiçbir şeyi herkese açık şekilde paylaşmayacaksın.
6. Yazardan gelen silme talebine istisnasız uyacaksın.
